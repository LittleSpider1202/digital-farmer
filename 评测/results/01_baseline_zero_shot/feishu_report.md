## 四、关键发现

### 4.1 Claude Opus 4.6 断层领先

Claude 识别率达到 100%，即使在未告知作物品种的情况下，也没有出现将小麦误判为其他作物的情况。总分 80.3%，高出第二名 22 个百分点。但 Claude 同时作为被测模型和评委，存在"自评偏高"的风险。

### 4.2 国内模型识别率差异大

- **Qwen** 识别率最高（70.6%），但症状描述和治疗方案深度不足
- **Seed** 识别率稍低（64.7%），但症状和治疗得分均为国内最高，诊断"质量"更好
- **GLM** 各项均垫底，尤其治疗方案质量较差（31.1%）

### 4.3 共性弱点：纹枯病和细菌性叶枯病

三家国内模型在纹枯病上表现最差，常见误判：
- Seed：未出现严重误判，但置信度偏低
- Qwen：误判为根腐病、霜霉病
- GLM：误判为大葱紫斑病、大葱软腐病（连作物都搞错）

细菌性叶枯病样本仅 4 张，所有国内模型识别率均为 0%，Seed 甚至判成了"水稻叶瘟"。

### 4.4 未告知品种导致跨作物误判

本次评测未在 prompt 中告知模型"这是小麦"，导致部分模型将病害误判为其他作物（水稻、大葱）。这说明在实际应用中，**必须在输入中明确作物品种**。后续实验（02_with_crop）将验证加入品种信息后的提升幅度。

## 五、结论与建议

1. **短期选型建议**：若走 API 路线，Seed-2.0-Pro 综合表现最佳（诊断质量最高）；若考虑性价比，Qwen3.5-Plus 延迟最低（15s）、识别率最高
2. **品种信息必须提供**：后续产品流程中，用户拍照前必须选择作物品种，系统将品种信息注入 prompt
3. **知识库增强是关键**：零样本模式下所有模型在治疗方案维度得分偏低（最高 62.5%），说明模型缺乏专业农业知识，后续需引入 RAG 增强
4. **评委独立性**：后续考虑引入第三方评委或交叉评审，避免 Claude 自评偏差
